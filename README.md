# 🌙 Serenity Hub

**A polished Roblox hub with a clean interface and straightforward game support.**

Serenity Hub is made to stay simple to use and easy to come back to. Open it with one loader, enter a supported game, and everything is ready from there.

</div>

- **Collect All the Leaves**
- **⚽ Jump To Steal Soccer Players ⚽**
- **+1 Drain Water Per Click**
- **Greedy Growers**
- **+1 Monkey Evolution**
- **+1 Superhero Evolution**
- **+1 Dino Evolution**
- **Chicken Farm 🐣**
- **+1 Cut Grass Adventure 🌿**
- **Sell Ores ⛏️**
- **Heroes RNG**
- **Cheating During Testing [BETA]**
- **Roll Anime to Fight!**

## Usage

```lua
loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/MUshihara/Serenity-hub/main/loader.lua"
))()
```

Run the loader while you are inside a supported game.
